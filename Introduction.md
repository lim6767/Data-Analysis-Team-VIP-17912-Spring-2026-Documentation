# Introduction
Greetings, future teammates. This GitHub page was made to help you understand where we are in the project so that you can start where we left off. To preface this (and not to discourage anyone), this project requires a deep level of general math knowledge, particularly in **linear algebra**, and also some experience in coding, like MATLAB or Python (I did this project with MATLAB).

Before we go into the code and math theory, understand the project goal:
> Project Goal: To develop a usable program that can be used for analyzing movements in stroke patients (and maybe other patients with movement issues).

This means we have to accomplish the following:
* Be able to derive joint angles from a patient's limb
* Use those joint angles and other tools to create a method for analyzing movement in patients (hint: we are thinking of using a cycling tool to extract information about the patient's movements)
